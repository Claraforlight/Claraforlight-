# Claraforlight-

## 💛 Nous Deux — l'appli de Clara & sa best

Une petite appli web (un seul fichier, `index.html`) pour :

- 📅 **Planning** — coller / écrire l'emploi du temps de la semaine, jour par jour
- 🏋️ **Sport** — noter les créneaux (1 muscu + 2 piscine), affichés dans le planning
- 🔗 **Partage** — un code à copier-coller pour se synchroniser entre deux téléphones
- 🎮 **Jeux** — 7 jeux : Qui de nous deux, On se connaît ?, Tu préfères ?, Jamais je n'ai,
  Action ou Vérité, 2 vérités 1 mensonge, Complète la phrase

Aucune installation, aucun compte. Les données sont enregistrées sur l'appareil (localStorage).

### 🌐 Mettre l'appli en ligne (lien public gratuit)

1. Sur GitHub : **Settings** → **Pages**
2. *Source* : **Deploy from a branch**
3. *Branch* : `claude/schedule-sharing-games-app-146sxa` (ou `main`) · dossier `/ (root)` → **Save**
4. Après ~1 minute, l'appli est en ligne ici :
   **https://claraforlight.github.io/claraforlight-/**

Ce lien s'ouvre sur n'importe quel téléphone, sans connexion. Il suffit de l'envoyer à ta best 💌
